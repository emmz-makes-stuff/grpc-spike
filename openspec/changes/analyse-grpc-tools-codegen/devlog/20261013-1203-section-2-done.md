# §2 Shape corpus and committed generated code done

<!-- Section: 2 · Tasks: 2.1–2.6 · Base: f20dbe2 -->

Emmz said "carry on with §2" after the §1 hand-off.

- 13 protos in `src/Corpus/protos/`, one shape each; generated C# lands in
  `src/Corpus/Generated/protos/` (`%(RelativeDir)` is `protos/`). The mapping is in `src/Corpus/README.md`.
- **Decision: `GrpcServices="None"` by default, `Both` only via `<Protobuf Update="protos/service.proto">`.**
  The design's blanket `GrpcServices="Both"` breaks the build: `grpc_csharp_plugin` writes no `*Grpc.cs` for a
  service-less proto, but Grpc.Tools still adds one to Compile (`CS2001`). This deviates from D4's literal
  item, not its intent.
- **Decision: the build forces regeneration** (`RegenerateCommittedCode` target in `Corpus.csproj` deletes
  `Generated/**/*.cs` before `Protobuf_BeforeCompile`). Found in self-review: Grpc.Tools' staleness check is
  timestamps of protos vs outputs, and a Grpc.Tools version bump is not an input. Without the target, D4's
  "build regenerates on every run" was false, and `make generated` could pass after a version bump. Proven:
  a hand edit that is *staged* gives `GENERATED_EXIT:1` after a build; an unstaged one is overwritten by the
  build.
- **Decision: nesting is one recursive `Node`**, with `Samples.Nested(depth)` building depths 1, 3 and 8.
  Rejected: 8 near-identical chained types. The generated code per level would be the same.
- **Decision: service methods are all `Scalars` → `Scalars`**, so §4's stub benchmarks aren't dominated by
  string decoding.
- `Samples.cs` lives in `src/Corpus` (not in the tests), so the §4 benchmarks reuse exactly the tested
  values. `RoundTripTests.EveryCorpusMessageHasPopulatedEmptyAndEdgeSamples` reflects over the assembly,
  so a new proto without samples fails the test gate.
- **Observation (subject behaviour, not an allocation finding):** a singular proto3 `double` holding `-0.0`
  does not round-trip in Google.Protobuf 3.36.2: the writer guards it with `!= 0D`
  (`Generated/protos/Scalars.cs:399`) while equality is bitwise (`:334`). The edge sample uses
  `double.Epsilon` instead; repeated `-0.0` does round-trip. Possibly worth a line in the §5 upstream survey.
- 2.5 negative check: corrupting the `ShortText` comparison in generated `Strings.Equals` gave
  `TEST_EXIT:2` (3 `Strings/*` round trips failed). Restored.
- Gotcha: the Bash tool's shell is zsh, so `${PIPESTATUS[0]}` is empty (zsh uses `$pipestatus`). Quote the
  `make` exit lines instead.
- Gotcha: `make generated` counts *untracked* generated files as drift, so `git add` new protos' output
  before running the gates.
